Hermes desktop plugin featuring cards to help keep track of all of Hermes most notable new features. The cards would follow a similar layout to my Achievments plugin, but would uniquely be their own. Cards should be sorted by each major release, with pre-release cards at the top. Cards should show the feature name, a description, be themeable by the native themes. Once a user explores the feature the feature should be marked as explored and be a dimmer color; on mouse hover the card can be brighter again incase the user wants to reread a card. on a major release of hermes, any prerelease cards should be moved to their release section when hermes has a new release. I'm not sure how much of this can be automated by the agent, or by me manually prompting the agent about new features I have seen the developers using and then building them in to the plugin and publishing a new version, or if the agent can create a new PR for me. If this could be handled in a local database, then maybe we wouldn't need to push PRs. The question I have is plugins don't have an update status, so the user has to take maintance updating on their own. so the most that we can build into a local database the better.
